02

기본 조작

창 옮기기Drag
상단 타이틀바를 누른 채 끌면 원하는 위치로 옮길 수 있어요.
접기 / 펼치기Focus
다른 곳을 클릭해 위젯이 포커스를 잃으면 달력만 남기고 자동으로 접혀요. 다시 클릭하면 원래대로 펼쳐집니다.
폭 조절Resize
창 우하단 모서리를 끌면 폭을 넓힐 수 있어요. 일정 제목이 길어서 잘릴 때 유용합니다.
다이어리 모드제목표시줄 아이콘
제목표시줄의 다이어리 아이콘을 누르면 옆으로 넓어지면서 달력·My Notes·오늘 일정을 한 화면에 다 보여주는 보드 형태로 바뀌어요. 달력/My Notes 사이 경계선을 잡고 좌우로 끌면 비율도 조절할 수 있고, 이 모드에선 다른 곳을 클릭해도 자동으로 안 접혀요. 다시 아이콘을 누르면 원래 위젯 크기로 돌아갑니다.
설정 메뉴⚙
톱니바퀴 아이콘에서 보기 모드, 테마, 반복 일정 관리, 자동 실행, 개인 캘린더 연동을 할 수 있어요.
알림🔔
종 아이콘을 누르면 최근 앱 업데이트 소식과, 팀 캘린더에 일정이 추가·수정·삭제된 내역(내가 올린 것도 포함)을 확인할 수 있어요. 안 읽은 게 있으면 빨간 점으로 표시됩니다.

04

일정 등록하기

날짜를 클릭하고 +를 누르면 등록 창이 열려요. 가장 먼저 고르는 건 Personal인지 Team Post인지입니다.

Personal

이 컴퓨터에만 저장됩니다. 팀 캘린더에는 절대 안 올라가요. 나만 보는 일정 메모용.

Team Post

구글 캘린더에 등록되어 팀원 전체에게 공유됩니다. "몰랐다"를 막는 진짜 목적이 여기 있어요.

05

My Notes

달력과 별개로 쓰는 개인 할 일 목록이에요. 아래 입력창에 적고 Enter만 누르면 됩니다. 이것도 이 컴퓨터에만 저장돼요. 일정 목록에서 + Add를 누르면 그 일정 제목을 바로 My Notes로 옮길 수도 있어요.

수정
항목의 글자 부분을 누르면 그 자리에서 바로 고칠 수 있어요.
하위 항목+ 버튼
항목 오른쪽의 +를 누르면 그 아래에 하위 항목을 하나 추가할 수 있어요(한 단계까지만 — 하위 항목의 하위 항목은 안 만들어져요).
순서 바꾸기
글자 부분을 누른 채로 위아래로 끌면 순서를 바꿀 수 있어요. 최상위 항목은 최상위끼리, 하위 항목은 같은 상위 항목의 하위 항목끼리만 순서가 바뀝니다.
06

그 밖의 기능

공휴일 표시
대한민국 공휴일이 자동으로 빨갛게 표시돼요. 설날·추석처럼 매년 날짜가 바뀌는 것도 알아서 반영됩니다.
테마
Light · Dark · Tack Style 세 가지 중 골라 쓸 수 있어요.
자동 실행
톱니 메뉴의 Start with Windows를 켜두면 컴퓨터 켤 때마다 자동으로 떠요.
자동 업데이트
실행할 때 한 번 새 버전이 있는지 확인해서, 있으면 "업데이트 하시겠습니까?"라고 물어봐요. Yes를 누르면 그때 받아서 알아서 재시작까지 끝납니다.
개인 캘린더 연동ICS
톱니 메뉴 → Personal Calendar (ICS)에서 본인의 개인 캘린더(구글·아웃룩·아이클라우드 등) 구독 주소를 넣으면, 그 일정이 이 컴퓨터에서만 보이는 개인 일정으로 같이 표시돼요. 팀 캘린더에는 전혀 영향 없습니다.
07

휴대폰·다른 캘린더에서도 보기

Team Post로 등록한 일정은 실제 구글 캘린더에 올라가기 때문에, 아이폰·아이패드·안드로이드(삼성) 기본 캘린더 앱에도 그대로 띄울 수 있어요. 아래 주소 하나만 복사해서 붙여넣으면 됩니다.

https://calendar.google.com/calendar/ical/4b9c15c5a0e715482c08ecf5b10482391754fd997bb4fe7d5b3615cb5991b31c%40group.calendar.google.com/public/basic.ics
아이폰Apple 캘린더
설정 → 캘린더 → 계정 → 계정 추가 → 기타 → 구독 캘린더 추가 → 위 주소 붙여넣기 → 저장
맥Apple 캘린더
캘린더 앱 → 파일 → 새로운 캘린더 구독 → 위 주소 붙여넣기 → 구독
안드로이드삼성 캘린더
Google 캘린더 앱 → 왼쪽 메뉴 → "다른 캘린더" 옆 ＋ → URL로 등록 → 위 주소 붙여넣기 → 캘린더 추가. 구글 계정이 동기화돼 있으면 삼성 캘린더 앱에도 자동으로 나타나요.

이 방법은 보기 전용이에요. 휴대폰에서 직접 일정을 추가·수정하려면 구글 계정 자체를 캘린더 앱에 추가해야 하고(설정 → 계정 추가 → Google), 그 계정에 팀 캘린더 편집 권한이 있어야 합니다.

08

자주 묻는 것

Personal이랑 Team Post, 나중에 바꿀 수 있나요?
수정 중엔 못 바꿔요. 저장 위치가 완전히 달라서, 실수를 막으려고 일부러 고정해뒀습니다.
업데이트하면 제 My Notes 내용이 사라지나요?
아니요. 실행 파일과 개인 데이터는 완전히 다른 폴더에 저장돼서, 몇 번을 업데이트해도 안전합니다.
위젯이 안 보여요.
항상 위에 떠 있는 창이라 다른 창에 가려질 일은 없어요. 작업표시줄에서 TKM Calendar 아이콘을 확인해보세요.
이제 "못 봤어요"는 안 통합니다
